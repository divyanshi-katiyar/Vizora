## 📌 About

**Vizora** is an interactive, modern data visualization tool engineered to make analytics accessible, clean, and actionable. Designed with performance and aesthetics in mind, Vizora allows users to explore datasets, uncover patterns, and present insights effortlessly.

---

## ✨ Features

- 📊 **Dynamic Dashboards:** Real-time updates with sleek, interactive charts and plots.
- 🎨 **Modern Interface:** Minimalist, clean UI with built-in dark and light mode support.
- ⚡ **High Performance:** Optimized data parsing and rendering pipeline.
- 📁 **Multi-Format Ingestion:** Import CSV, JSON, and standard tabular database formats.
- 📤 **Instant Export:** Export reports and visual figures directly into PNG, SVG, or PDF.
